# Portfolio scope

- Keep this repository a focused publication of portfolio material; do not add product features, unrelated refactors, or production-certification claims.
- Preserve privacy, ownership, and publication boundaries. Do not copy private product data or infer customer acceptance.
- Quantitative and consequential behavior claims need traceable evidence and a stated proof limit; unknown remains unknown.
- Prefer deterministic checks and existing generators. Do not add a dependency, test framework, CI, or hosted service for this documentation-only repository.
- Regenerate diagrams only through the existing diagram generator.
- Stop this readiness sweep when its local acceptance criteria pass.
